Conseil de saisie

Commence par créer les compagnies, puis les avions et les aéroports. Ensuite crée les vols, puis les utilisateurs, les réservations, les billets et enfin les paiements.

Pour les relations, les formulaires utilisent la logique d'IDs du backend : par exemple pour un vol, il faut fournir l'ID de la compagnie, de l'avion, de l'aéroport de départ et de l'aéroport d'arrivée.
